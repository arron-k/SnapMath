# SnapMath — Phase 4 개발 노트 (부모 계정 + 학습 이력)

> **목적:** "부모가 가입하고 자녀 프로필을 만들면, 아이가 푼 기록이 쌓이고 부모가 진척·오답을 확인하는" 흐름을 비개발자도 이해할 수 있게 정리한 문서.
> **한 줄 요약:** 부모가 로그인 → 자녀 프로필(별명·학년)을 동의와 함께 생성 → 아이가 그 프로필로 학습 → 부모 대시보드에서 정답률·오답 노트 확인.

---

## 0. 무엇이 새로 생겼나 (사용자 눈높이)

1. **부모 로그인이 생겼다.** 화면 위 오른쪽에 "부모 로그인" 버튼. 이메일·비밀번호로 가입/로그인한다. (아이는 가입하지 않는다.)
2. **자녀 프로필을 만든다.** 별명과 학년·학기만 입력한다. 실명·학교·연락처는 받지 않는다. 만들 때 "무엇을·왜·언제까지 저장하는지" 쉬운 말 안내와 **부모 동의 체크**가 있고, 동의해야 기록이 저장된다.
3. **아이는 프로필을 골라 학습한다.** 자녀가 여럿이면 위쪽 스위처로 누가 푸는지 고른다.
4. **학습이 자동으로 기록된다.** 도전 문제를 맞히거나 틀리고 넘어가면 "어떤 단원·맞았는지·몇 번 시도·얼마나 걸렸는지"가 그 프로필에 쌓인다. **사진은 저장하지 않는다.**
5. **부모 대시보드(`/history`)가 생겼다.** 정답률·푼 문제 수·학습한 날, 그리고 **오답 노트**(자주 틀린 단원)와 최근 학습 목록을 본다.
6. **오답 단원은 바로 다시 도전**할 수 있다. 오답 노트의 "다시 도전"을 누르면 그 단원의 비슷한 문제를 새로 받아 연습한다(`/practice`).
7. **시작하려면 회원가입이 필요하다.** (정책 변경 — 아래 5-ter) 사진 찍기/올리기를 누르면 미로그인 시 회원가입으로, 자녀가 없으면 자녀 등록으로 자연스럽게 안내된다.

## 1. 화면 흐름

```
[헤더: 부모 로그인]
   ↓ 가입/로그인 (/login)
[자녀 프로필 (/children)]
   · 별명 + 학년 + 학기
   · "무엇을/왜/언제까지" 안내 + 부모 동의 체크   ← 동의해야 저장
   · 자녀 여럿이면 프로필 스위처
   ↓ 활성 프로필 선택
[문제 풀이 → 도전 (기존 Phase 1~3)]
   · 도전 정답/오답 시 → learning_history에 기록 (사진 제외)
   ↓
[부모 대시보드 (/history)]
   · 정답률 · 푼 문제 · 학습일
   · 오답 노트(단원별) → "다시 도전" → /practice (단원 재연습)
   · 최근 학습 목록
```

> **중요(규칙 6·프라이버시):** 부모만 가입한다. 자녀는 별명·학년만. 동의(`consent_at`) 전에는 저장하지 않는다. 사진 원본은 저장하지 않고 문제 텍스트만 남긴다. RLS로 **다른 부모의 데이터는 절대 보이지 않는다**.

## 3. 데이터·프라이버시 설계 (규칙 6)

- **부모 계정 = Supabase Auth.** 자녀 자격증명은 수집하지 않는다.
- **child_profiles:** 별명·학년·학기·동의시각(`consent_at`)만. 식별정보 컬럼 없음.
- **learning_history:** 단원·개념·정답여부·시도·걸린시간·문제텍스트. **사진·실명 없음.**
- **RLS(행 수준 보안):** 부모는 `parent_id = auth.uid()`인 자기 자녀와 그 학습 기록만 읽고 쓴다. 다른 부모 데이터는 쿼리 자체가 막힌다.
- **question_id:** 지금은 비워둔 nullable. Phase 5에서 문항 풀(`questions`)이 생기면 FK로 연결할 자리.
- **graceful:** Supabase 키가 없으면 로그인/저장만 비활성, Phase 1~3 학습은 그대로 된다.

## 4. 디자인·접근성 적용 (claude.md 트렌드 매핑)

- **T1 마이크로 인터랙션:** 드롭다운/카드 페이드, 버튼 scale.
- **T4 다크 모드:** 새 화면(로그인·자녀·대시보드·연습) 모두 다크 토큰 사용.
- **T5 접근성:** 정답=초록+체크, 오답=보라+점 **이중표시**(색만으로 알리지 않음). `aria-live`로 결과 읽어줌. 터치 타겟 48px+. 메뉴 `role`/`aria-expanded`.
- **T6 콘텐츠 퍼스트:** 대시보드는 통계 3카드 → 오답 노트 → 최근 학습의 단순 위계.
- **T9 맥락적 프라이버시:** 자녀 생성 화면에서 "무엇을·왜·언제까지" 저장하는지 그 자리에서 쉬운 말로 안내 + 동의 체크.

## 5-bis. 학습자 선택 UX 개편 (실사용 피드백 · L-1~L-3)

처음엔 "지금 누가 학습 중인지"가 메인 어디에도 안 보였고, 자녀가 여러 명일 때 누구로 푸는지 고를 동선이 없었다. 활성 학습자를 **앱 전역에서 항상 보이게** 끌어올렸다.

### 🎯 무엇이 달라졌나 (사용자 눈높이)
1. **헤더에 "○○ 학습 중" 칩이 늘 보인다.** 문제 풀이·도전 등 모든 화면에서 지금 누구 기록인지 확인된다. 탭하면 학습자 전환.
2. **자녀가 여럿이면 큰 아바타 시트로 고른다.** 아이가 자기 얼굴(별명 첫 글자) 타일을 직접 탭 — 활성은 테두리+체크로 표시.
3. **홈 화면에 "지금 학습하는 친구" 카드.** N명이면 "바꾸기"로 시트 열기.
4. **자녀가 없으면(로그인 상태) 등록을 부드럽게 유도.** 헤더 "자녀 등록" + 홈 넛지 카드.
5. 학습자 전환 자체엔 강제가 없다 — 기본 학습자를 쓰고 언제든 바꾼다. (단, 학습 *시작*은 회원가입·자녀 등록을 거친다 — 5-ter)

## 5-ter. 회원가입 필수 게이트 (정책 변경 · L-4)

**이전 원칙(미로그인 1회성 학습 허용)을 뒤집어, 회원가입을 사실상 필수로 바꿨다.** 단, 벽을 세우지 않고 **시작 행동에서 자연스럽게** 가입/등록으로 흐르게 했다.

### 🎯 무엇이 달라졌나 (사용자 눈높이)
1. **미로그인 + "사진 찍기/올리기"** → 카메라/파일창 대신 **회원가입 화면**(`/login?mode=signup`, 회원가입 탭 기본). 가입/로그인 후 **원래 자리로 자동 복귀**.
2. **로그인했지만 자녀 0명 + 시작** → **자녀 등록 화면(`/children`)**으로 유도.
3. **홈 게스트 카드** — "회원가입하면 기록이 쌓여요 + [회원가입하고 시작하기]".
4. 준비된 사용자(로그인+자녀)는 평소처럼 바로 촬영/업로드.
